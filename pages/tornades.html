LES TORNADES.

Une tornade est une colonne d'air en rotation intense qui se développe sous certaines conditions convectives.

🌀 Supercellules 🚨 Sécurité
🌪️

01 • FORMATION

COMMENT SE FORME UNE TORNADE ?

Les conditions nécessaires peuvent être complexes.
💨

Cisaillement

Les variations du vent avec l'altitude favorisent l'organisation.

🌀

Rotation

La rotation peut être amplifiée dans certaines structures orageuses.

⬆️

Ascendance

Un courant ascendant puissant peut modifier cette rotation.

🌪️

Tornade

Dans certaines situations, une rotation intense atteint le sol.

02 • SÉCURITÉ

RESPECTER LA PUISSANCE.

Une tornade peut être extrêmement dangereuse. L'observation doit toujours respecter les consignes officielles et conserver une marge de sécurité importante.
